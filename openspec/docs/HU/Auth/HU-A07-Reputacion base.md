# HU-A07 — Reputación base

**Épica:** A — Auth & Users  
**Sprint:** 1

## Historia de usuario

**Como:** Usuario verificado  
**Quiero:** Tener una reputación que refleje mi actividad  
**Para:** Que mis votos pesen más cuando demuestre experiencia

## Criterios de aceptación

- Todo usuario nuevo empieza con reputación base (ej. 1.0).
- La reputación se calcula con: antigüedad, votos emitidos, consistencia, reportes recibidos.
- Usuarios con reputación baja o señales de bot tienen peso reducido.
- La reputación es visible en el perfil.
